How to Make a PowerPoint Template

Updated October 1, 2026 · 9 minute read · How these guides are written

To make a PowerPoint template: set your slide size and theme on a blank presentation, edit View → Slide Master to define layouts and branding, then use File → Save As and change the file type to PowerPoint Template (*.potx). Save it into your Custom Office Templates folder so it appears under File → New → Personal.

A good template pays for itself the third time you use it. The trick is that a template is not just "a deck with the logo on it" — it is a theme, a set of layouts, and a default slide size bundled into one file that starts every future presentation at the right baseline.

If you have not used Slide Master before, read how to use Slide Master first — this guide assumes you know what the parent master and the layouts are.

Step by step

  1. Start from a blank presentation

    File → New → Blank Presentation. Do not start from an existing deck, even a good one: every piece of hand-formatting in it comes along and quietly overrides the layout, which is exactly the problem templates exist to solve.

  2. Set the slide size first

    Design → Slide Size → Widescreen (16:9).

    Do this before you build anything. Changing slide size later forces PowerPoint to rescale or crop every element you have placed, and it rarely does it gracefully. It is two clicks now and an afternoon of repositioning later.

    Presenting on an unusual screen? Use Custom Slide Size here to set exact dimensions. Still do it first.

  3. Define the theme colors and fonts

    On the Design tab, open Colors → Customize Colors and enter your brand palette. Give the colors meaningful names — "Accent 1" tells you nothing, "Brand Blue" does.

    Then open Fonts → Customize Fonts and set a heading font and a body font. This pairing is what every placeholder in the template will use, so getting it right here means you never set a font again.

    Stick to widely available fonts — Arial, Georgia, Calibri, Verdana, Trebuchet. A template built on an exotic font falls apart the moment a colleague without that font opens it, and text reflows in ways that ruin your layouts.

  4. Edit the Slide Master

    View → Slide Master. Select the large parent thumbnail at the top and set the background, then confirm the theme fonts and colors are applied.

    Everything you set on the parent is inherited by every layout beneath it. This is the step that makes the template a template rather than a saved deck.

  5. Add the branding that appears on every slide

    Still on the parent master, insert your logo with Insert → Pictures. Place it where it will not collide with content — a corner is conventional for a reason.

    For footers, dates and slide numbers, do not reach for Insert Placeholder — that command makes content placeholders for text, pictures, charts and media, not page furniture. The three you want already exist. Every layout ships with footer placeholders, and they inherit their position and formatting from the slide master, so one edit there updates every slide automatically.

    What they are is switched off. Turn them on with Insert → Header & Footer and select Apply to All. Use Slide Master → Master Layout → Footers to control whether the master carries them at all.

  6. Delete the layouts you will not use

    Right-click any layout thumbnail you will never use and choose Delete Layout. A stock file ships with about a dozen.

    This matters more in a template than anywhere else. Every layout you keep is an option your colleagues will have to scroll past for the next two years. Keep four or five good ones and delete the rest.

  7. Close Master View and clear the sample content

    Click Close Master View, then delete any placeholder text and example slides so the template opens clean. A template that opens with "Click to add subtitle" and three leftover sample slides trains people to ignore it.

    Leave the first slide as a title slide layout, empty. Starting a new presentation on a properly laid-out title slide is worth a lot.

  8. Save as a PowerPoint Template

    File → Save As, then change the file type dropdown at the bottom from PowerPoint Presentation (*.pptx) to PowerPoint Template (*.potx).

    This is the step people miss. A file saved as .pptx is a presentation — it will open as a deck, not as a template, no matter how it is built.

  9. Save it to the Custom Office Templates folder

    For the template to appear under File → New → Personal, it has to live in a specific folder:

    Windows: C:\Users\<your name>\Documents\Custom Office Templates
    Mac: /Users/<your name>/Library/Group Containers/UBF8T346G9.Office/User Content/Templates

    If that folder does not exist, create it — PowerPoint creates it automatically on some versions and not on others, and a template saved elsewhere simply will not show up in the gallery. You can check or change the location in File → Options → Save → Default personal templates location.

  10. Test it by creating a presentation from it

    Use File → New → Personal and pick your template. Check that the fonts, colors, logo and layouts all come through, and that New Slide offers only the layouts you kept.

    Double-clicking a .potx creates a new presentation from it, which is the correct behaviour. To edit the template itself, right-click the file and choose Open — otherwise you will spend twenty minutes editing what you think is the template and wondering why the changes never stick.

Sharing the template with a team

  • Publish it to a shared network folder For a team, put the .potx somewhere everyone can reach and point each person's Default personal templates location at it. Everyone then sees the same up-to-date template with no file copying.
  • Embed the fonts before you distribute it File → Options → Save → Embed fonts in the file. Without this, anyone missing your brand font sees substituted type and reflowed layouts. Only do this with fonts whose licence permits embedding.
  • Send a sample deck alongside it A short one-page example of the template in use prevents more misuse than any amount of documentation, because it shows what the layouts are actually for.

When it does not work

  • My template does not appear under File → New → Personal Two causes, in order of likelihood: it was saved as .pptx rather than .potx, or it is in the wrong folder. Confirm the file extension first, then move the file into the Custom Office Templates folder inside your Documents folder and restart PowerPoint.
  • When other people use it, the fonts change They do not have your font installed, so PowerPoint substitutes a different one and your careful layout reflows. Either embed the fonts (File → Options → Save → Embed fonts in the file), or switch the template to fonts that ship with Windows and Office.
  • My changes to the template do not stick You are almost certainly editing a document created from the template rather than the template file itself. Double-clicking a .potx makes a new presentation. To edit the template, right-click the file and choose Open.
  • Colors will not change on slides The familiar direct-formatting problem — someone applied manual colors that override the theme. On an existing deck, use Home → Reset per slide. In a new template, make sure you have not been formatting text by hand instead of using theme colors.
  • The template file is very large Usually high-resolution images on the master. File → Info → Compress Media handles video (Windows only), and for images select any picture and use Picture Format → Compress Pictures — untick Apply only to this picture so the setting covers the whole template in one pass. A template gets copied into every new deck, so its size is multiplied across everything your team creates.

Frequently asked questions

What is the difference between a PowerPoint template and a theme?
A template (.potx) contains everything: theme, master slides, layouts, sample content and settings. A theme (.thmx) contains only the color scheme, font pair and effect styles, with no layouts or content. Use a theme to restyle an existing deck; use a template to start a new one.
Why doesn't my template appear under File → New → Personal?
Either it is saved as .pptx instead of .potx, or it is in the wrong folder. Personal templates must sit in the Custom Office Templates folder inside your Documents folder. Check the path under File → Options → Save → Default personal templates location.
How do I stop fonts changing when someone else opens my template?
Embed the fonts: File → Options → Save → Embed fonts in the file. Note that embedding is only permitted for fonts whose licence allows it, which is why template designers usually choose widely available fonts instead.
Do I need to use Slide Master to make a template?
Yes, for anything genuinely reusable. The master is where layouts, placeholders and always-present branding are defined — a "template" built without touching it is just a saved set of slides that happens to be empty.
Can I create a PowerPoint template in the web app?
No. The web app can open and use a template, but it cannot save a .potx file and does not support Slide Master editing. Template creation is desktop-only.

The test of a good template

Hand it to someone who has never seen it, ask for a five-slide deck, and watch. If they never open the font dropdown or the color picker, the template is doing its job.
