The file size checker is provided free, as it is. It reads the file in your browser and reports what it finds; nothing is uploaded, which is covered on the privacy page.

  • It is a diagnostic, not a repair tool. It reads your file and tells you what is inside it. It never modifies the file and never writes anything back to it.

  • Its numbers are advisory. The size breakdown is meant to tell you where to look. Treat a surprising figure as a reason to check, not as a verdict.
